# DEBT-0067 — Uncalled Ontological Helpers in Runtime Lifetime Domain

Status: **OPEN** · Filed: 2026-08-07 · Channel: CER-3 / CER-1
Level: **runtime-lifetime** (touches `runtime/lifetime.py`).
Source: Checkpoint Audit Loop (Constitutional Drift Audit).

## 1. Observation

`classify_obj` and `is_institutional` were added to `runtime/lifetime.py` and exported in `__all__`. However, neither function is referenced anywhere in `runtime/`, `kernel/`, `ops/`, or `tests/`.

Adding un-derived speculative utility functions to the runtime lifetime ontology without callers or unit test coverage increases un-tested surface area and violates CER-1 (minimizing un-derived abstractions).

## 2. Root Cause

Speculative extension of the IP-0006 lifetime ontology during lifetime helper refactoring without immediate caller integration or test coverage.

## 3. Remediation Strategy

- **Short-term:** Retain the functions if callers are planned in an upcoming task, but add unit tests in `tests/runtime/test_lifetime.py`.
- **Long-term:** Remove un-referenced helpers until a concrete requirement and test suite exist.
