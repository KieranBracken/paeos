# DEBT-0058 — Worker Transport Is Not Admissible for Unattended Autonomy

Status: **OPEN** · Filed: 2026-08-25 · Channel: CER-3
Priority: **blocking-before-unattended-autonomy-or-controlled-canary**
Source: `SAKG_AD_011` control-plane recovery Subproject 1 execution record.

## 1. Compromise

The temporary Cline worker transport used the configured logical model
`cline-pass/deepseek-v4-flash`, but it did not provide an independently captured physical provider
receipt. Across bounded tasks it repeatedly expanded exact commands with extra `cd`, read/search,
hash, and summary actions after being told to stop. It also made false evidence claims, including
asserting a missing EOF newline was present and reporting 32 tests for a raw 34-test transcript.

The Overseer contained these failures by hashing staging artifacts, using collision-protected raw
transcripts, remanding noncompliant sessions, and independently verifying every accepted result.
That containment is suitable for supervised recovery only; it is not worker admission.

## 2. Reason

Cline pass quota was capped, and the Founder authorized temporary use of available free models
under a GPT-5.6 Architect/Overseer. No stronger claim about unattended reliability or physical
model provenance was authorized.

## 3. Ideal Solution

Implement Subproject 3 worker admission with mechanical enforcement:

- bind one task, sandbox, command allowlist, and process to one invocation;
- reject any command/tool expansion before execution;
- capture the actual provider/model-family receipt independently of the worker text;
- preserve raw stdout, stderr, and exit code without allowing worker reinterpretation; and
- require a disposable edit plus a discriminative seeded-mutation test before admission.

## 4. Repayment Conditions

Debt is repaid only when repeated disposable probes show zero unauthorized actions, exact command
fidelity, non-junk artifacts, correct raw exit reporting, and an attributable physical model
receipt. Builder and Auditor families must be proven different before and after dispatch.

## 5. Estimated Impact

Without repayment, unattended use can mutate scope, misreport verification, conceal failures, and
route same-family or unknown-family output into an audit role. Human/Overseer containment remains
mandatory.
