# DEBT-0061 — L14 Report Is Not Bound to Its Physical Receipt or Canonical Counts

Status: **OPEN** · Filed: 2026-08-30 · Channel: CER-3
Priority: **blocking-before-Gate-C-seal**
Source: Gate C headless-supervisor receipt review; Notebook Entry 175.

## 1. Compromise

The current L14 receipt records transport and transcript digests but not a digest of the
persisted auditor report. The report validator also permits a report whose operational counts
contradict the bound prompt and canonical ledger. A genuine non-GLM physical receipt can
therefore coexist with an unbound or hallucinated report.

## 2. Reason

Task 9A implemented minimum candidate/provider binding and one-shot A-08 checks first. The
missing report-content/accounting binding was exposed only when the external headless report
claimed `Admitted: 1` and `Sealed: 1` despite canonical counts of zero admissions and zero seals.

## 3. Ideal solution

Persist a cryptographic report-content digest in the receipt, atomically bind receipt/report/
ledger snapshot, and enforce a structured accounting schema that rejects contradictory counts.
Add mutation tests for report swapping, missing counts, and false success counts.

## 4. Repayment conditions

Debt is repaid only after the strengthened schema is designed and independently audited, a
receipt/report swap fails closed, the current false-count report is rejected, legacy artifacts
are explicitly classified, and a fresh candidate-bound non-GLM L14/L17 evidence bundle passes.

## 5. Estimated impact

Until repaid, false operational success claims can contaminate Gate/Court accounting and cause
premature lifecycle advancement. This debt blocks Gate C sealing and all downstream autonomous
dispatch.
