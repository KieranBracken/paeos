# DEBT-0102 — Version Control Tracking of Transient SQLite WAL/SHM Binary Files in `state_sakg/`

Status: **OPEN** · Filed: 2026-08-08 · Channel: CER-3
Level: **ops-sakg** (touches `.gitignore`, `state_sakg/`).
Source: Checkpoint Audit Loop (Constitutional Drift Audit).

## 1. Observation

Commit `f152160` (`feat(sakg): complete and seal all 20 intakes for SAKG Mission 1`) committed transient SQLite write-ahead log (`ledger.db-wal`) and shared memory (`ledger.db-shm`) files into git tracking under `state_sakg/`.

Storing active SQLite transaction log files in git causes non-deterministic binary diffs, repo bloat, and potential DB corruption across branch checkouts.

## 2. Root Cause

Missing `*.db-wal` and `*.db-shm` rules in `.gitignore`.

## 3. Remediation Strategy

- **Short-term:** Remove `state_sakg/ledger.db-wal` and `state_sakg/ledger.db-shm` from git tracking (`git rm --cached`) and add `*.db-wal` and `*.db-shm` to `.gitignore`.
- **Long-term:** Audit all state directories to ensure binary runtime state files are excluded from version control.
