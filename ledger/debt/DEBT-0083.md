## 2. Root Cause

In `concept/model.py`, `SemanticNeighborhood.center_uri` is typed as `ConceptURI | str | None = None`. In the serialization branch `_thaw_neighborhood()` (line 320):

```python
"center_uri": _uri_str(self.center_uri)
```

`_uri_str()` accepts only `ConceptURI | str`, but `self.center_uri` may be `None`. If `self.center_uri` is `None`, calling `_uri_str(None)` is an invalid type assignment.
