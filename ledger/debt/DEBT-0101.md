# DEBT-0101 — Tacit Read Scope Escalation in `RoleSpec` Without Architecture Spec Update

Status: **OPEN** · Filed: 2026-08-08 · Channel: CER-3
Level: **runtime-agents** (touches `runtime/agents/__init__.py`).
Source: Checkpoint Audit Loop (Constitutional Drift Audit).

## 1. Observation

`read_scopes` for `_DESIGN` and `_PLAN` in `runtime/agents/__init__.py` were expanded from `("constitution/", "spec/", "design/")` / `("constitution/", "design/", "plan/")` to include 6 additional directories (`reviews/`, `ledger/`, `backlog/`, `docs/`, `architecture/`, `operations/`).

`PAEOS-7.6-runtime-interface-contracts.md` and `PAEOS-9-execution-architecture.md` define role capability profiles as formal contracts. Modifying role read scopes in Python code without updating the corresponding spec files or ratifying an Improvement Proposal creates spec-implementation divergence.

## 2. Root Cause

Ad-hoc expansion of role capability definitions in code without updating `spec/PAEOS-7.6-runtime-interface-contracts.md`.

## 3. Remediation Strategy

- **Short-term:** Update `spec/PAEOS-7.6-runtime-interface-contracts.md` to document the authorized read scopes for `_DESIGN` and `_PLAN` roles.
- **Long-term:** Enforce automated validation between `runtime/agents/__init__.py` and `spec/PAEOS-7.6-runtime-interface-contracts.md`.
