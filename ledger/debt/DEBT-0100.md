# DEBT-0100 — Hardcoded Repository Directory Whitelist (`VALID_TOP_DIRS`) in `runtime/selfhost.py`

Status: **OPEN** · Filed: 2026-08-08 · Channel: CER-3
Level: **runtime-selfhost** (touches `runtime/selfhost.py`).
Source: Checkpoint Audit Loop (Constitutional Drift Audit).

## 1. Observation

`runtime/selfhost.py` defines `VALID_TOP_DIRS` as a hardcoded static tuple of 23 top-level directory names.

Any new top-level directory added to the repository in future work (e.g., `mcp/`, `benchmarks/`, `services/`) will be silently ignored by runtime path inference. Conversely, any path starting with one of these 23 hardcoded strings gets matched. This tightly couples system execution logic to specific folder names.

## 2. Root Cause

Embedding repository directory schema directly into runtime code instead of inspecting workspace topology or using generic path normalization.

## 3. Remediation Strategy

- **Short-term:** Replace static `VALID_TOP_DIRS` tuple with dynamic workspace directory discovery or clean path normalization against workspace roots.
- **Long-term:** Decouple runtime capability enforcement from hardcoded folder names.
