## 1. Compromise

PAEOS currently relies on a hybrid governance architecture composed of:
1. Deterministic kernel enforcement (`kernel/`);
2. Independently observed physical evidence (e.g. host transcript bindings);
3. Test-only enforcement (properties checked only during `pytest` invocations);
4. Policy/procedural enforcement (documented conventions and human review protocols);
5. Model-instruction enforcement (system prompts, role instructions, and behavioral guidance).

While PAEOS constitutional doctrine mandates deterministic guarantees and non-vacuous evidence, critical invariants across the lifecycle are still enforced procedurally, through worker/model compliance, via test mocks, or by locally asserted evidence rather than by unbypassable runtime mechanisms.

This programme is a **horizontal hardening initiative across the existing canonical lifecycle and runtime**. It is **NOT** a replacement lifecycle, not an L20 stage, and not a parallel governance system. Canonical stages L01 through L19 remain strictly authoritative.

---

## 2. Core Problem & Motivating Evidence

The system has repeatedly demonstrated that **process compliance does not guarantee physical correctness where a critical invariant remains model-mediated**. Models will follow instructions until ambiguous edge conditions, context pressure, or tool hallucination intervene; tests will pass against synthetic mocks while production entrypoints remain unexercised.

Recent forensic evidence classes motivating this systemic hardening programme include:
- **Self-Asserted Auditor Identity:** External auditor identity at Layer 14 was initially self-assertable by the calling agent rather than cryptographically derived from host-level execution truth (`reviews/tasks/P1_L14_ANTIGRAVITY_SESSION_PROVENANCE_FORENSIC.md`).
- **Locally Signed Receipts for External Execution:** A locally minted Ed25519 signature was capable of describing remote/external model execution without independently proving the contemporaneous transmission or receipt of bytes (`reviews/tasks/P1_L14_EXTERNAL_PROVENANCE_PHYSICAL_BINDING.md`).
- **Test-Only Production Components:** Critical orchestrators (such as `PersistentMissionController`) initially existed solely within test fixtures before being integrated into production execution paths (`runtime/orchestrator/`, `ops/autonomous_run.py`).
- **Synthetic Controller-Death Verification:** Controller crash/restart tests initially verified restart logic against in-memory synthetic state before real production process death (`SIGKILL`) and native SQLite ledger replay were physically demonstrated (`reviews/tasks/PRE_P2_AUTONOMY_READINESS_GATE_COURT_DISPOSITION.md`, Scenario 14).
- **Predetermined Negative CANARY Codes:** Negative CANARY controls initially returned predetermined exit codes and static error objects rather than executing authentic production rejection paths and capturing genuine exception crashes.
- **Model-Loop Convergence Stagnation:** Autonomous execution sessions spent extensive time looping on model-mediated decisions without measurable state convergence because control flow remained open-ended rather than bound to deterministic state-machine fences.

These incidents are not isolated defects; they represent a single systemic architectural class:
> **SOFT GUARANTEE / TRUSTED-AI SURFACE**

## 3. Programme Objective & Target State

The objective of this programme is to systematically:
> **Identify every critical authority, evidence, provenance, state, promotion, recovery, convergence, and architecture guarantee that currently depends on model compliance, documentation, procedural convention, test-only enforcement, or locally asserted evidence, and convert the appropriate guarantees into deterministic or independently observable runtime mechanisms.**

The programme enforces the strict hardening hierarchy:
```text
MAKE INVALID STATE IMPOSSIBLE
        ↓
INDEPENDENTLY OBSERVE
        ↓
DETECT
        ↓
WARN
        ↓
MODEL INSTRUCTION
```

The programme must measurably reduce the amount of PAEOS correctness that depends on model intelligence, obedience, or unverified claims.
