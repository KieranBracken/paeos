# 🧪 PAEOS Research Backlog (`backlog/research/`)

This directory is designated for **rough ideas, exploratory concepts, raw research notes, and unformed hypotheses** before they are formally triaged into the canonical backlog (`backlog/PAEOS-5-backlog.yaml`) or drafted as Improvement Proposals (`proposals/`).

---

## 📌 How Ideas Move Through Research Intake:

```
Rough Idea / Research Note  (backlog/research/)
            │
            ▼  (Triage at Stage L02 / Stage L05)
 ┌──────────────────────┴──────────────────────┐
 │                                             │
 ▼                                             ▼
Canonical Task Backlog             Improvement Proposal
(backlog/PAEOS-5-backlog.yaml)      (proposals/PAEOS-IP-XXXX.md)
```

---

## 📝 Format for Research Notes (Flexible & Lightweight):

Feel free to create `.md` files in this directory using any informal structure. Suggested template:

```markdown
# [Idea Title]

Date: YYYY-MM-DD
Status: DRAFT / EXPLORATORY

## 💡 Summary
A high-level description of the idea or problem.

## 🎯 Motivation & Expected Value
Why is this worth exploring? What problem does it solve?

```
