## What this delivers

The autonomous-evidence flow, now vendor-shaped: one `ClaudeCliWorkerTransport` is used by the
`SoftLoop` as **both** `agent_runtime` (it runs the sessions) **and** `evidence_source` (the agent's
own declared evidence). Running the IMPLEMENT session captures the evidence the session wrote —
**no pre-declared backlog evidence** — which then passes the full gauntlet (B2.I binding → B2.N
probative court → B2.O vacuous gate → B2.K adversary gate). Tested: the loop seals autonomously on
agent-declared evidence.

the existing `AgentRuntime` seam. The core loop depends on `AgentRuntime`/`WorkerTransport`/

### 3–7. Duplication / Simplicity / Derivation / Debt

reach the core runtime. Captured evidence still faces the whole verification/adversary gauntlet, so
an agent cannot seal on non-probative or forged evidence it declares.

### 9–10. Runtime / Extensibility

behind the same `WorkerTransport`, zero core-runtime change.
