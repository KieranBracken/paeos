## Evaluation Checklist

### 1. Constitutional Compliance
**PASS.** The court **reproduces every claim** and remands on any unmet one (§4.3 G-Court / §4.4);
`submit_evidence` is **inert** until `adjudicate` (SI-2). Reproduction runs in the DEBT-0005 sandbox
(untrusted agent commands re-run resource-limited). The kernel decides the result, not the agent (T2).

### 2. Architectural Drift
**PASS.** The court reuses `verify_deterministic` (B0.7) — no re-implementation of reproduction; the
sandbox is injected as a `runner`, so `evidence.py` gains an *optional* seam without a hard
kernel→sandbox coupling. The sandbox is behind an implicit seam so a container adapter drops in later.

### 3. Duplication of Mechanisms
**PASS.** Reproduction, binding, and canary loading are reused; the court composes them into a verdict.

### 4. Bypassing Mechanisms
**PASS.** A claim with no evidence, or evidence never submitted, is treated as **unmet** (deny-by-
default) — the court cannot be passed by omission. A timed-out sandbox run reports a non-success exit,
so a hanging command can't masquerade as a pass.

### 5. Simpler Implementation Possible
**PASS.** `setrlimit` + `subprocess` (stdlib) for the sandbox; the court is a pool + a fold over claims.

### 6. Better Derivation
**PASS.** `PASS ⟺ every claim reproduced` is the direct G-Court rule; the sandbox runner maps timeout→
124 so "no result" never reads as success.

### 7. Hidden Technical Debt
**PASS.** DEBT-0005 is *repaid* for resource/DoS protection and re-scoped to LOW (container isolation =
deploy-env residual, Observation 1). No new hidden debt.

### 8. Security Implications
**PASS — this closes the T2 loop end-to-end.** Adversary pass below. Untrusted commands now run with
CPU/memory/fd/file-size caps, a wallclock kill, a minimal env (no inherited secrets), and a scoped cwd.
A forged result and a planted canary are both **caught** and remanded.

### 9. Runtime Implications
**PASS.** Best-effort `setrlimit` (skips a limit a platform rejects, so macOS + Linux CI both work);
`preexec_fn` applies limits in the child; timeouts are handled.

### 10. Future Extensibility
**PASS.** A container `Sandbox` adapter, and richer verdicts (mutation testing, adversarial coverage),
extend behind the existing seams; B1.D/G consume the court's verdict.
